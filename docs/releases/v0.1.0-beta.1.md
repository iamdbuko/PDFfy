# PDFfy 0.1.0-beta.1

The first PDFfy beta brings **PDF to Figma** and **Figma to PDF** into one plugin. Switch directions while keeping your file queue and export settings. The original Figma-to-PDF exporter remains a separate plugin.

## What's included

- Import multiple PDFs, preview pages, and select thumbnails or page ranges.
- Convert supported PDF text, vectors, and images into editable layers, or import pages as images at 1×–4× density.
- Arrange pages vertically, horizontally, or in a grid; set spacing and grid columns.
- Open password-protected PDFs, detect and replace fonts, and preserve supported web and included-page links.
- Keep the existing PDF export options: page ordering and sizes, links, vector/raster output, resolution, PNG/JPEG, color profiles, experimental CMYK, split output, progress, and cancellation.
- Process conversions locally without a separate account, watermark, or import-count quota.

## Beta notes

Figma Design only. Text may need font or spacing adjustments, and outlined letters stay vectors. Scans stay images; OCR is not included. Complex effects may require Page images. Import does not match embedded print color profiles, and CMYK export is experimental rather than PDF/X. Vector export can recompress embedded images.

The current import limits are 128 MiB per PDF and 256 MiB in the queue, with additional image and drawing-complexity limits. Review the converted result before using it in a final deliverable.

## Validation

All **340 local tests passed**. The installed macOS Figma Desktop plugin was checked with editable and image imports, ranges, batch/password handling, font remapping, undo, cancellation, and RGB/CMYK export round trips. Native external-link retention was verified in a saved raster PDF. Typography and image-compression differences were observed and documented.

Native internal-link navigation and other operating systems/browser workflows have not yet received the same end-to-end check. See [beta validation](../BETA-VALIDATION.md) for the evidence and limitations.

At the time these notes were prepared, hosted GitHub CI, the GitHub release, and Figma Community publication were pending. This document alone does not confirm public availability.
